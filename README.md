# Sister Kinetochore Oscillation Analysis

Python pipeline for quantifying sister kinetochore oscillation dynamics from MATLAB KiT/maki output files.

Associated with: Skendo et al., [Journal], [Year]

---

## What this does

Extracts cross-correlation curves from MATLAB `.fig` files generated by the `makiSisterMotionCoupling` function of the [KiT pipeline](https://github.com/cmcb-warwick/KiT), then:

- Plots mean ± 95% CI cross-correlation curves per condition
- Quantifies **oscillation amplitude** (peak minus anti-correlation trough)
- Estimates **oscillation period** via damped cosine fitting
- Runs statistics (Kruskal-Wallis + Dunn-Bonferroni or ANOVA + Tukey HSD)
- Exports Prism-ready `.csv` files for amplitude and period

## Requirements

Python 3.11 or newer.

Install dependencies:

```bash
pip install h5py numpy scipy matplotlib
```

---

## File naming convention

All `.fig` files must follow this pattern:

```
<condition>_<replicate>_<anything>.fig
```

Examples:
```
siCTRL_1_makiAnalysis__1-MotionCoupling-Inlier.fig
siCTRL_2_makiAnalysis__1-MotionCoupling-Inlier.fig
siHAUS6_1_makiAnalysis__1-MotionCoupling-Inlier.fig
siHAUS6siHURP_1_makiAnalysis__1-MotionCoupling-Inlier.fig
```

Replicate numbers can be any integer (0, 1, 2, 3 ...).

## Usage

1. Place all `.fig` files in one folder
2. Open `sister_KT_oscillations.py` and set `DATA_DIR` to that folder:

```python
DATA_DIR = r"C:\Users\you\Desktop\your-fig-folder"   # Windows
DATA_DIR = "/Users/you/Desktop/your-fig-folder"       # Mac/Linux
```

3. Run:

```bash
py sister_KT_oscillations.py        # Windows
python3 sister_KT_oscillations.py   # Mac/Linux
```

- **B** — Oscillation amplitude per KT pair (Prism-style box + scatter plot)

## Statistical approach

For each metric (amplitude and period), statistics are computed at the level of **individual kinetochore pairs** (n = 50–80 per condition across all replicates):

1. Normality assessed per group using Shapiro-Wilk test (subsample of 50)
2. If all groups normal → **one-way ANOVA + Tukey HSD**
3. If any group non-normal → **Kruskal-Wallis + Dunn (Bonferroni correction)**
4. All comparisons vs siCTRL
